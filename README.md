# Yuvraj Gandhmal — Portfolio

React, TypeScript, Vite, and Motion portfolio.

## Development

- `npm install`
- `npm run dev`
- `npm run lint`
- `npm run build`
- `npm test` (requires Chrome)

## Content and media
